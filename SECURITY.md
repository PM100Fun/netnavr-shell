# Security Policy

This pre-alpha source has no supported production release. Keep local services
on loopback and use disposable test workspaces while validating the prototype.

Use [private vulnerability reporting](https://github.com/PM100Fun/netnavr-shell/security/advisories/new)
when available. If unavailable, contact the [repository owner](https://github.com/PM100Fun)
privately before sharing sensitive details. Do not put provider credentials,
personal data, exploit payloads or private logs in public issues. Include source
commits, environment, impact and a minimal reproduction. No bounty is offered.
