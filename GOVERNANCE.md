# Governance

NetNavr is maintainer-led. The repository owner approves project direction,
releases, security disclosure and governance changes. Changes should be small,
reviewable and supported by reproducible evidence.

Core and Shell are independently versioned. Product candidates bind exact source
commits and must pass applicable integration and human acceptance before an
authorized release. A source push is not product acceptance or an App release.
Public issues and PRs record public technical decisions; internal planning stays
outside the source repositories.
